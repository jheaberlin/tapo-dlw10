# Security policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** option in the repository's
Security tab. Do not open a public issue containing credentials, tokens,
control keys, session data, device secrets, packet captures, or enough network
details to identify a home.

Include the integration version, Home Assistant version, lock model and
firmware, impact, and the smallest safe reproduction you can provide. Redact
all personal and device-specific values. You should receive an acknowledgement
within seven days.

If a physical lock may be left in an unsafe state, secure it manually first and
disable the integration until the behavior is understood.
